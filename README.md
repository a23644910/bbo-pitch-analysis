# BBO 投球分析（全民打棒球2）

即時讀取遊戲畫面，逐球記錄對手的投球落點、球種、球速與結果，在網頁上顯示九宮格分析和下一球參考。

## 下載與安裝（Windows）
1. 下載：[main.zip](https://github.com/a23644910/bbo-pitch-analysis/archive/refs/heads/main.zip)，解壓縮到桌面。
2. 雙擊 `1_第一次安裝.bat`（第一次約 5～15 分鐘，會自動安裝 Python 和需要的套件）。
3. 之後每次用 `2_啟動.bat` 開啟，瀏覽器會自動打開分析網頁。
4. 第一次在網頁右上「設定」輸入自己的遊戲 ID。

遊戲請用**視窗模式**、畫面比例 16:9。

## 更新
有新版本時網頁上方會出現「更新並重新啟動」，按一下即可；紀錄和設定不會被覆蓋。也可以雙擊 `更新.bat`。

## 有問題時
遊戲停在打擊畫面，雙擊 `3_診斷（有問題時用）.bat`，把產生的 `診斷結果.zip` 傳給開發者。

詳細說明見 `使用說明.txt`。
